# khaao：米飯、新聞、白色

日常最實用的一組：點餐、看新聞、講顏色都會用到。四個字只差在聲調。

| 聲調 | 例字 | 意思 | 為什麼念這個調（依 [[tone-rules]]） |
|---|---|---|---|
| 中 | คาว khaao（中） | 腥味 | 低類 ค＋活音節、無符號 |
| 低 | ข่าว khàao（低） | 新聞 | 高類 ข＋่ |
| 降 | ข้าว khâao（降） | 米飯 | 高類 ข＋้ |
| 升 | ขาว khǎao（升） | 白色 | 高類 ข＋活音節、無符號 |

- 例字和意思來自 S06；「為什麼」那一欄是用 S05 的規則表推出來的，四個字都對得上。
- 這組沒有高調的實際字。
- 小心：ข้าว khâao（降）米飯 和 ข่าว khàao（低）新聞 只差在聲調，點餐時念錯，對方可能聽不懂。
