概念子音三類泰文的子音字母分成高類、中類、低類三組。看泰文判斷聲調時，第一步就是看這個字的開頭子音屬於哪一類。
來源：S03, S05概念五個聲調總覽標準泰語（Standard Thai）有五個聲調（tone）。同一個音節換了聲調，意思就不一樣。
來源：S01, S02, S04, S05, S06概念活音節與死音節泰文的聲調規則會看「音節怎麼結尾」。結尾可以拉長的是活音節，結尾突然停住的是死音節。
來源：S01, S05概念五個聲調的音高曲線聲調就是「音高怎麼走」。這一頁用聲學量測的結果，說明五個聲調實際聽起來的樣子。
來源：S02, S03, S04概念說話時聲調會變字典上的聲調是「單字念」的樣子。實際說話時，有些音節的聲調會改變。這一頁給聽力練習用：聽到的聲調跟字典不同，不一定是自己聽錯。
來源：S01概念四個聲調符號泰語有五個聲調，但只有四個寫在字上方的聲調符號（S05）。不加符號也是一種寫法。
來源：S04, S05概念聲調的標記法拼音本身看不出聲調，所以要加符號。常見的標法有兩種：母音上的符號、五度數字。
來源：S03概念聲調規則表看到一個泰文字，怎麼知道它念哪個聲調？要看三件事：開頭子音的類別、活音節還是死音節、有沒有聲調符號。
來源：S01, S05概念母音長短泰語的母音有長短之分，長短不同，意思就不同。對台灣學習者來說，這跟聲調一樣重要。
來源：S01例字日常容易念錯的字組這幾組字很常用，而且只差在聲調。念錯的話，意思會差很多。
來源：S05, S06例字khaa 的五個聲調國際語音學會「IPA 圖解」（S01）示範泰語聲調時用的例字：同一個音節 khaa，五個聲調，五種意思。
來源：S01, S03, S05例字khaao：米飯、新聞、白色日常最實用的一組：點餐、看新聞、講顏色都會用到。四個字只差在聲調。
來源：S05, S06例字naa 的五個聲調另一組常見的五聲調例字：同一個音節 naa，五個聲調，五種意思。
來源：S03, S04易錯不能直接套用國語四聲台灣人學泰語，很自然會拿國語的四聲來對照。有些可以對，有些對了反而會念錯。
來源：S02, S03, S04, S07易錯升調不是「最低的調」有些教學網站把五個聲調排成一條由高到低的音階，說「高調最高、升調最低」（S06）。照這個說法練習，會把升調念成一個平平的低音，聽起來就不對了…
來源：S02, S03, S04, S06易錯拼音不標聲調等於沒寫靠拼音學泰語的人，最容易漏掉聲調。拼音如果不標聲調，好幾個不同的字會寫成一模一樣。
來源：S03, S06易錯符號名稱不等於聲調聲調符號 ◌่ 叫 ไม้เอก（mai ek），低調的泰文名稱也叫 เอก（S04）。很多人因此以為「看到 ◌่ 就念低調」。這只對一半。
